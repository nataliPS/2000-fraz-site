# orizolabs.com

Сайт Orizo Labs на GitHub Pages (гілка `main`, корінь репозиторію).

| Сторінка | Файл |
| --- | --- |
| Компанія (укр.) | `index.html` |
| Company (EN) | `en/index.html` |
| Застосунок «2000 фраз» | `2000/index.html` |
| Підтримка (Support URL для App Store) | `support.html` |
| Політика конфіденційності (Privacy URL) | `privacy.html` |

Стилі — `assets/site.css`, логотипи та зображення — `assets/`.
Кольори бренду: #14213D, #1F4FD1, #F2C200, #F6F7FB. Шрифти: Rubik, IBM Plex Sans.

Шлях `privacy.html` не змінюється: на нього посилаються застосунок і App Store.
