# orizolabs.com

Сайт освітньої компанії Orizo Labs на GitHub Pages (гілка `main`, корінь репозиторію).

| Сторінка | Файл |
| --- | --- |
| Компанія (укр.) | `index.html` |
| Company (EN) | `en/index.html` |
| Продукт «2000 фраз» | `2000/index.html` |
| Продукт «Академія готовності» | `academy/index.html` |
| Підтримка (Support URL для App Store) | `support.html` |
| Політика конфіденційності «2000 фраз» (Privacy URL) | `privacy.html` |

## Як влаштовано

- **Рамка компанії спільна:** шапка з логотипом Orizo, підвал з колонками «Продукти / Компанія / Допомога», кольори
  Orizo (#14213D, #F2C200, #F6F7FB), шрифти Rubik і IBM Plex Sans. Стилі — `assets/site.css`.
- **Кожен продукт має своє обличчя:** клас на `<body>` задає колір героя й акцент
  (`p-2000` — синій і жовтий, `p-academy` — темно-синій, золотий і теплий фон).
- **Сторінка продукту — один шаблон:** герой (статус, назва, одне речення, мови/платформи, кнопка) →
  «що всередині» → «як працює» → «для кого» → доступ і запитання → спільний підвал.

## Як додати новий продукт

1. Скопіюйте `academy/` у нову папку, напр. `jobs/`.
2. Додайте в `site.css` клас продукту: `.p-jobs{--hero:…;--hero-soft:…;--p-accent:…;--p-accent-ink:…}`.
3. Замініть тексти й ілюстрації (у `assets/<продукт>/`).
4. Додайте картку в розділ «Продукти» на `index.html` і `en/index.html`
   та посилання в колонку «Продукти» підвалу на всіх сторінках.

Шлях `privacy.html` не змінюється: на нього посилаються застосунок і App Store.
