# orizolabs.com

Сайт освітньої компанії Orizo Labs на GitHub Pages (гілка `main`, корінь репозиторію).

| Сторінка | Файл |
| --- | --- |
| Компанія (укр.) | `index.html` |
| Company (EN) | `en/index.html` |
| Продукт «2000 фраз» | `2000/index.html` |
| Напрям «Цивільна безпека» (коротка сторінка) | `academy/index.html` |
| Напрям «Професійна підготовка» з PSDinfo (коротка сторінка) | `psdinfo/index.html` |
| Підтримка (Support URL для App Store) | `support.html` |
| Політика конфіденційності «2000 фраз» (Privacy URL) | `privacy.html` |
| Політика конфіденційності застосунку напряму «Цивільна безпека» (Privacy URL для App Store, ручна; не видаляти й не переносити) | `academy/privacy.html` |

## Мови і як редагувати тексти

Сайт має 7 мов: українська (корінь), `en/`, `pl/`, `lt/`, `lv/`, `et/`, `sk/`.
Сторінки **генеруються** — не правте HTML у цих папках вручну.

- Тексти: `_src/i18n/<мова>.json` (однакові ключі в усіх мовах).
- Розмітка: `_src/templates/*.html`.
- Зібрати: `python3 _src/build.py` (також оновлює `sitemap.xml`), потім закомітити.
- `privacy.html` і `404.html` — ручні (UA/EN).

## Як влаштовано

- **Рамка компанії спільна:** шапка з логотипом Orizo, підвал з колонками «Продукти / Компанія / Допомога», кольори
  Orizo (#14213D, #F2C200, #F6F7FB), шрифти Rubik і IBM Plex Sans. Стилі — `assets/site.css`.
- **Кожен продукт має своє обличчя:** клас на `<body>` задає колір героя й акцент
  (`p-2000` — синій і жовтий, `p-academy` — темно-синій, золотий і теплий фон).
- **Сторінка продукту — один шаблон:** герой (статус, назва, одне речення, мови/платформи, кнопка) →
  «що всередині» → «як працює» → «для кого» → доступ і запитання → спільний підвал.

## Як додати новий продукт

1. Скопіюйте шаблон `_src/templates/p2000.html` як основу нової сторінки.
2. Додайте в `site.css` клас продукту: `.p-jobs{--hero:…;--hero-soft:…;--p-accent:…;--p-accent-ink:…}`.
3. Замініть тексти й ілюстрації (у `assets/<продукт>/`).
4. Додайте шаблон у `_src/templates/`, сторінку в `PAGES` у `_src/build.py`,
   картку в `home.html`, посилання в `_foot.html` і тексти в усі `_src/i18n/*.json`.

Шляхи `privacy.html` і `academy/privacy.html` не змінюються: на них посилаються застосунки й App Store.

**Конфіденційність (рішення власника, 30.10.2026):** сайт не розкриває внутрішніх деталей продуктів у розробці —
без скриншотів, цифр, переліків функцій, цін і планів. Сторінки напрямів — лише коротка місія й статус «У розробці».
Сторінки для інвесторів на сайті немає; партнерам — лист на hello@orizolabs.com.
