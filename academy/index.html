Для кого

Для родин

Спокійно підготувати дім, дітей і близьких, не панікуючи і не витрачаючи зайвого.

Для шкіл і вчителів

Готові уроки й іспити для класів, з поясненнями простою мовою.

Для громад і волонтерів

Спільна підготовка мешканців, навчання для груп і журнал інструктора.

Для Європи

Досвід України для мешканців Литви, Латвії, Польщі та інших країн, де готовність стала частиною життя.

Лише цивільне й захисне: як розпізнати загрозу і захистити себе та інших. Без бойової тактики, зброї чи інструкцій, що можуть зашкодити.
